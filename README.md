# Age Calculator 🎂

## Project Description
A simple Python program that calculates the user's age based on their date of birth.

The program displays the user's age in days and years, then checks whether they are 18 years old or older.

## Features
- Enter date of birth.
- Calculate age in days.
- Calculate approximate age in years.
- Check adult status.

## Technologies Used
- Python 3
- datetime module

## Purpose
A beginner Python project to practice date calculations and conditional statements.
